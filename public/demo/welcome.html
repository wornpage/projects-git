Use a real workspace

A working workspace uses Cloudflare Access for its owner, assigned agents and independent reviewers. Configure your own workspace and identity policy; this example grants no workspace access.

What an owner does next
  1. Connect committed project code and queue useful tasks with written requirements.
  2. Give the assigned agent the project's instructions in your coding conversation.
  3. Configure independent checks and assign a separate reviewer.
  4. In Project settings, optionally enable automatic integration for eligible candidates. Otherwise accept and merge manually. Resolve alternatives and exceptions while agents continue other eligible work.
