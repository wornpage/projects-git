## Copy usable for the source-and-sample release

**Name:** Projects Git

**Tagline:** Keep agent changes, checks and merge decisions together.

**Short description:** Projects Git is an open-source workspace for coding-agent
work. Keep tasks, candidate changes, checks, independent reviews and merge
decisions together. Explore a fictional example without signing up, or use the
Cloudflare-first setup guide.

**Release introduction:**

Projects Git started as a Cloudflare Git challenge prototype. This follow-up adds
installation checks, repository permissions, recovery tools and clearer records
of where work spends time. It also adds bounded workspace backup, optional GitHub
delivery from your machine and four read-only tools for compatible browsers.

The public example needs no account. It uses invented records and performs no
live operations. The MIT source is available for a Cloudflare-hosted installation.
An open hosted trial is being prepared; it is not available yet.

This is a developing project. The current hosted proof is a maintainer read/UI
smoke, not an independently verified installation or an enterprise-readiness claim.

**Suggested developer-community title:**

Projects Git: keep coding-agent changes, reviews and merge evidence together

**Maker comment:**

I built Projects Git because getting code from an agent leaves another job: keep
the task, understand what was checked, get a separate review and decide what to
merge. I wanted those records to stay with the project, including failed attempts.

You can inspect the sample without an account. It is fictional and read-only;
the application source and Cloudflare setup guide are public. I would especially
like feedback on whether the task-to-review path is clear, and what would prevent
you from trying it with your own coding agent.
